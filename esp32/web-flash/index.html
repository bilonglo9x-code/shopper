Hướng dẫn Flash

  1. Kết nối board ESP32-S3 với máy tính qua cáp USB-C
  2. Mở trang này bằng Google Chrome hoặc Microsoft Edge
  3. Nhấn nút "Kết nối & Flash" bên dưới
  4. Chọn cổng COM/serial của board trong popup
  5. Đợi quá trình flash hoàn tất (khoảng 2-3 phút)
Trình duyệt không hỗ trợ Web Serial. Vui lòng dùng Chrome hoặc Edge trên desktop. Trang web cần chạy trên HTTPS để sử dụng Web Serial.

Sau khi Flash

  1. Board sẽ tự khởi động và hiển thị giao diện setup WiFi
  2. Kết nối WiFi cho board (nhấn giữ BOOT 3 giây để vào chế độ config)
  3. Board sẽ tự kết nối tới server AI và sẵn sàng sử dụng
